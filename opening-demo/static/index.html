What is actually enabled?

Basic: one Python tool and its normal loop. Harness: history, compaction, todos, plan/execute mode, file memory, file access, installed skills, a helper agent and up to six continuation iterations. Python and skill helpers are custom host tools. Native web search is optional. Detailed local events are always recorded; OpenTelemetry export is optional (see README). No agenda-specific tools, validators, workbook templates, or quality scores.
